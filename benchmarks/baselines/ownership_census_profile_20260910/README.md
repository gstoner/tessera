`package-census.json` is generated by `scripts/record_package_route_census.py`.
It records source hashes, first-argument types and direct call sites: 45 Graph
inputs, 14 scheduled inputs and 13 raw/unclassified inputs. These are input
boundaries, not 45 independent semantic reconstructors. In particular x86
`package_matmul` now forwards f32 and BF16 to Schedule/Tile but still constructs
Tile for uint8/int8 and fp64. No constructor deletion is authorized by this count.

`x86-bf16.txt` records three passing cases on Princess-Luna's Zen 5 CPU: BF16
Schedule/Tile projection and tamper rejection, plus native execution for
(5,8,7) and (2,17,9) M/K/N shapes. BF16 inputs are compared against f32 matmul
of their exact stored values. The assertions compiler was built on Super-Bear;
execution uses Princess-Luna's own x86 runtime library. This is x86 proof,
not ROCm GPU evidence.

`cuda-isolation.json` and `rocm-isolation.json` independently bind native ANN
artifacts inside fresh processes, verify checked host outputs, stop an idle
worker before sending a request, observe timeout, confirm process death and
verify a replacement. This is a SIGSTOP process/transport fault. It does not
prove recovery from a hung GPU or driver. Worker mode is opt-in, device zero,
with one outstanding request; no external device pointers are transported.

Both profiler runs use 32x8 terminal-square ANN with fused elementwise and
row-parallel consumers. Every run verifies the numerical oracle. The 64x8
probe refuses at the existing 4096-byte temporary bound; row-parallel lowering
still reserves full matrix temporaries per thread. A per-row storage projection
requires a separate ownership proof rather than simply increasing the bound.

- `cuda-nsys.csv`: 88 kernel launches, median 3.328 us; median H2D/D2H device
  copies 0.256/0.288 us. Median host launch API 24.082 us and D2H API 97.821 us.
  These aggregates include warmup and oracle probes, not just paired trials.
- `cuda-ncu.csv`: two instrumented kernels, durations 5.09/2.24 us and achieved
  occupancy 2.08%. Grid is one block; this workload cannot occupy the device.
  Counter replay durations must not be substituted for uninstrumented timing.
- `rocm-trace/` and `rocm-api-summary.json`: HIP API evidence only. Median launch
  API 24.741 us and device-synchronize API 80.144 us. No kernel/copy timeline was
  emitted despite requesting both. The list-available probe additionally aborts
  during PC-sampling discovery because `/dev/kfd` cannot be opened on this WSL
  host; the exact failure is retained separately.

instrumented runs, not nine independent promotion runs. No candidate is promoted.

larger multi-block schedules and independent uninstrumented comparisons.
