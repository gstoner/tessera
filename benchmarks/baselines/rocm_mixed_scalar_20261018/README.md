## Boundary and numerical evidence

Typed Graph entries reach native Schedule/Tile/ROCm Target/LLVM/HSACO
packages for static compact FP32 by FP16/BF16 contractions, with either wide
operand, both physical transposes and FP32/FP16/BF16 output stores. Python JIT
proof covers FP32/FP16 output policies and original argument permutations;
literal Graph MLIR/package proof additionally covers BF16 output. FP32 input
values survive increasing-K FP32 FMA; only final stores narrow. This is a VALU
consumer, with no FP32 WMMA or general composed-AD claim.

Owning RX9070XT/gfx1201 and Radeon8060S/gfx1151 each pass 67 package/public
cases, including compiler-free changed-root replay, argument permutations,
canaries, immutable output snapshots, strict runtime dimensions, stage lineage,
FP32 cancellation, subnormal/nonfinite classification and reuse across
17x19x35 and 7x11x13. The selected mixed native request rejects unsupported fused contracts before
any eager fallback. Scope remains the named contraction and host packages.

The shared emitter retains all 48 pre-change NVIDIA Target IR identities.

370 cases with no skips. The adjacent gfx1201 quantized/owner lane passes 110.

Ruff and the mypy ratchet pass. Publication gates are recorded in validation.json. Initial gates exposed a recorder index

## Timing characterization

Each architecture's JSON contains 48 correctness-gated profiles and five
samples per timing region. Measurements characterize the named compiled route; they do not establish a speedup.

| Owning device | Native event-window median range | Prepared update/invoke/read | Completed descriptor call |
|---|---:|---:|---:|
|gfx1201 RX9070XT|6.44–17.52 us|0.358–0.684 ms|0.882–1.212 ms|
|gfx1151 Radeon8060S|4.04–6.39 us|0.355–0.476 ms|0.931–1.155 ms|

Native event windows are divided by 256 repeats in C++ and may include
submission gaps. Prepared host costs include root refresh and result read.
Descriptor costs include validation, native owner acquire/upload, execute/read
and release. These quantities are separate; ordinary descriptor receipts report
no kernel time. No producer stage exists in this standalone consumer packet.

Both packets have identical Python-source and compiler-binary hashes.
Architecture-specific images and provider identities remain separate.
source-identity.json binds the native source files; JSON records image, entry,
ABI, dtype/orientation, device and per-row timing evidence. Deterministic
dyadic inputs and changed roots are regenerated by the source-bound recorder
and asserted before and during timing.

and the native C++ program provider. Confirm the intended live GPU.

    TESSERA_ROCM_SCALAR_DEVICE_PROOF=1 python -m pytest tests/device/rocm/test_scalar_matmul_package.py -q

Use --architecture gfx1151 on Princess-Luna. Compiler and native provider
fingerprints belong to that execution; sibling receipts do not transfer.
