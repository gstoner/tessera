# Math-source workstream — consolidated status

MSW-1–MSW-8 are implemented bounded reference/calculus/example work. Their
historical tests and limitations are preserved in the archive; they are not
native backend closure. MSW-9 has bounded fragment extraction and native pair
integration, while automatic discovery, image-to-fragment binding and measured
admission remain owned by [ANN_CALCULUS_DESIGN_SPIKE.md](ANN_CALCULUS_DESIGN_SPIKE.md)
and foundation F3 in the integrated plan.

Native higher-order execution belongs to [AUTODIFF_EXECUTION_PLAN.md](AUTODIFF_EXECUTION_PLAN.md).
Coordinate/PDE descent belongs to [PDE_STENCIL_CAPABILITY_PLAN.md](PDE_STENCIL_CAPABILITY_PLAN.md).
The contraction reference algebra is not evidence of a native rewrite pass.
No original MSW ID is reopened or silently declared generally complete.
